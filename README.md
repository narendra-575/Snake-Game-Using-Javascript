# Snake-Game-Using-Javascript
# 🐍 Classic Snake Game

A responsive, retro-inspired 2D Snake Game built from the ground up using pure **Vanilla JavaScript**, **HTML5**, and **CSS3**.

---

## 🌟 Key Features

* 🎮 **Smooth Controls**: Responsive keyboard directional movement (Arrow keys).
* 🧱 **Dynamic Grid Calculation**: Board auto-computes rows and columns based on viewport dimensions.
* 🍎 **Food Spawning & Growth**: Random coordinates generation with dynamic snake body expansion.
* 💥 **Full Collision Detection**:
  * Wall boundary collision
  * Self-body collision detection
* 🏆 **High Score Persistence**: Automatically saves your highest score using browser `localStorage`.
* ⏱️ **Live Game Stats**: Real-time timer and current score tracking.
* 🛑 **Interactive Modals**: Polished Start Game and Game Over restart overlay screens.

---

## 🛠️ Built With

* **HTML5**: Semantic layout & modal structure
* **CSS3**: Custom properties (variables), Flexbox, CSS Grid layouts
* **JavaScript (ES6+)**: DOM manipulation, `setInterval` game loops, event handling

---

## 🚀 How to Play

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/snake-game.git
   ```
2. Open `index.html` in your browser.
3. Click **"Start Game"**.
4. Use the **Arrow Keys** (⬆️ ⬇️ ⬅️ ➡️) to steer the snake.
5. Eat the food to score points, grow longer, and set a new high score!
